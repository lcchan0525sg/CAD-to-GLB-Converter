# CAD Converter 2 V0.32 Release Notes

## Improvements

- Runs CAD conversion on a background worker so the native Win32 UI stays responsive.
- Returns preview, assembly tree, statistics, output path, and timing to the UI thread after conversion completes.
- Prevents closing the application while an active conversion is still finishing.
- Removes the selectable Draco option when OCCT was built with `USE_DRACO=OFF`.
- Keeps Meshopt compression correctly mapped in non-Draco builds.
- Updates the application title and heading to V0.32.

## Compression availability

This build of OCCT 8.0.1 has `USE_DRACO=OFF`. Its Compression list therefore contains:

- `none`
- `Meshopt (STL only)`

Draco must only be shown in a package linked against a Draco-enabled OCCT build.

## Validation

- Visual Studio 2022 x64 Release build passed.
- Background STL conversion generated a valid GLB 2.0 file.
- Compression-mode binary inspection confirmed the unavailable Draco item is absent and Meshopt remains present.
