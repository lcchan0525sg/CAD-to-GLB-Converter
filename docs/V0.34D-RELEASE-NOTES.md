# CAD Converter 2 V0.34D Release Notes

## Main release line

V0.34D is the next Draco-enabled native build after V0.33D.

## Improvements

- Routes STEP and IGES previews through the OCCT XCAF presentation path.
- Preserves original per-part CAD colors in the interactive preview instead of rendering every CAD model with the native blue STL material.
- Keeps the native OpenGL preview for STL input.
- Preserves the V0.33D GLB integrity gate and STEP/IGES assembly-preservation checks.
- Preserves the V0.33D compact action-row layout and dynamic result-area reflow.

## Validation

- Visual Studio 2022 x64 Release build passed.
- GearBox STEP preview displayed multiple original colors, including the blue housing, gray cover, and red shaft.
- GearBox STEP conversion and assembly tree remained functional.
- GearBox STEP, GearBox IGES, simple STEP, and Menger STL regression checks remain covered by `scripts/run_regression.py`.
- Older V0.33D artifacts remain preserved separately.
