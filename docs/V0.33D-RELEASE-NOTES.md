# CAD Converter 2 V0.33D Release Notes

## Main release line

V0.33D is the maintained main build. It uses the Draco-enabled OCCT 8.0.1 runtime and keeps the `-D` output suffix convention.

## Improvements

- Simplifies output handling to a single post-conversion `Download` action.
- Keeps Convert, Cancel, and Download in one tidy action row and expands the assembly tree and preview when conversion results are hidden.
- Stages converted GLB/GLTF output in Windows temporary storage instead of asking for an output path before conversion.
- Opens the native Windows Save dialog only after a successful conversion, allowing the user to choose the final destination.
- Adds overwrite handling through the native Save dialog.
- Cleans staged temporary output when a new conversion starts, conversion fails or is cancelled, or the application closes.
- Adds phase-based progress reporting for preparation, import, meshing, export, validation, and completion.
- Adds real cancellation support through OCCT progress indicators and cancelable `gltfpack.exe` execution.
- Validates GLB/GLTF integrity and STEP/IGES assembly preservation before enabling Download.
- Adds repeatable regression verification using real GearBox STEP/IGES and Menger STL fixtures.
- Keeps the V0.33D Draco naming convention and emits `-D` output filenames.

## Validation

- Visual Studio 2022 x64 Release build passed.
- Isolated V0.33D build passed with OCCT 8.0.1 Draco runtime.
- Temporary STL conversion generated a valid GLB 2.0 file.
- GearBox STEP passed with one root, 45 component meshes, preserved hierarchy, names, and basic colors.
- GearBox IGES passed with one root, 45 component meshes, preserved hierarchy, 45 fallback part names, and basic colors.
- Menger STL passed the production conversion path and runtime integrity gate.
- Native V0.33D runtime displayed one Download button after conversion and no pre-conversion output-path controls.
